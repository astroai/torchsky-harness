These fixtures are copied from Astropy's packaged VOTable test data and are used as real-data catalog compatibility inputs for torchsky.

Files:
- `irsa-nph-m31.xml`: IRSA 2MASS PSC query around M31
- `vizier_b2_votable.xml`: VizieR MASH planetary nebula catalog sample
- `binary2_masked_strings.xml`: Gaia DR2 sample query result

Source paths in the installed Astropy distribution:
- `astropy/io/votable/tests/data/irsa-nph-m31.xml`
- `astropy/io/votable/tests/data/vizier_b2_votable.xml`
- `astropy/io/votable/tests/data/binary2_masked_strings.xml`
